# Thenuja – Developer Portfolio

A minimal, OS-inspired developer portfolio built to showcase my work, skills, and experience in a clean and interactive way.

## ✨ Overview
This project is a personal portfolio website designed with a desktop-style UI, window management, and theme support.  
It focuses on clarity, performance, and a polished user experience rather than overloading visuals.

## 🛠 Tech Stack
- HTML5  
- CSS3 (Custom Properties / Themes)  
- Vanilla JavaScript  

## 🎯 Features
- Desktop-style UI with draggable windows  
- Light / Dark theme support  
- Modular window system (Home, About, Work, CV, Contact)  
- Responsive design for mobile and desktop  
- Clean, professional color palette
